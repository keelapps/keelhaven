# Getting Started

::: warning Draft
Keelhaven has not shipped its first public release yet. This guide is a
placeholder and will be completed alongside the first public beta.
:::

Keelhaven backs up the folders you choose to a destination you control — a
local disk, a network volume, or an S3-compatible bucket — as an encrypted
[restic](https://restic.net) repository. restic is bundled with the app, so
there is nothing extra to install.

## The short version

1. [Install Keelhaven](./installation.md) and open it from the menu bar.
2. Create a backup plan: pick the folders to protect and where to send them.
3. Choose a schedule — hourly, daily, or weekly.
4. That's it. Keelhaven runs your backups in the background and tells you if
   anything needs attention.
