# Installation

::: warning Draft
Keelhaven has not shipped its first public release yet. Download links will
appear here with the first public beta.
:::

## Requirements

- macOS 14 (Sonoma) or later
- Apple Silicon or Intel

Nothing else. [restic](https://restic.net) is bundled inside the app, so there
is no separate install step and no Homebrew requirement — see
[Open source licenses](/licenses) for its copyright notice.

## A note on beta builds

Beta builds are signed ad-hoc and are **not notarised yet**, so macOS will
refuse to open one on the first attempt. Notarised builds will ship with the
first public release; until then, expect Gatekeeper to object and to have to
allow the app explicitly in **System Settings › Privacy & Security**.
