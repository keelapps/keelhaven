# 隐私

Keelhaven 的构建方式，让这里几乎没有什么需要写成政策的东西。

- **没有账号。** 没有任何需要注册的东西，你对这个应用的使用不与任何身份绑定。
- **没有遥测。** 应用不会「回传数据」——没有分析统计、没有崩溃上报、没有使用数据。
- **没有我们的服务器。** 你的备份从你的 Mac 直达你配置的目的地——本地硬盘、你的 NAS，或你自己的 S3 兼容存储桶。Keelhaven 不运营任何能看到它们的服务器。
- **离开之前已加密。** 在任何一个字节上传之前，所有内容都已在你的 Mac 上完成加密。仓库密码只存放在你的 macOS 钥匙串中，绝不会被发送到任何地方。

以上覆盖了应用本身——也就是接触你文件的那部分。围绕它还有两件事值得明说：

- **这个网站**是由 GitHub Pages 提供的静态站点；和任何网站托管商一样，GitHub 能看到它所服务的请求。网站使用 Google Analytics 做基础访问统计——这是唯一涉及的第三方，并且只作用于网站，从不作用于应用。
- **支持邮件**发到我们的地址后，经 Cloudflare Email Routing 转发到我们阅读的邮箱。我们会看到你的地址和你写的内容，并且只用它们来回复你。

有疑问？看看[常见问题](/zh/#faq)，或给我们写邮件——地址在网站页脚。
